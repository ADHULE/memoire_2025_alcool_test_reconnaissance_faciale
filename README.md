Ce projet a pour objectif de développer un système intelligent de contrôle et de suivi des chauffeurs de véhicules, combinant un capteur d’alcool et la technologie de reconnaissance faciale.

Fonctionnalités principales
Enregistrement des chauffeurs :
Le système permet d’ajouter les informations personnelles et professionnelles des chauffeurs dans une base de données sécurisée.

Reconnaissance faciale :
Un module de reconnaissance faciale est utilisé pour identifier de manière fiable chaque chauffeur avant le contrôle, garantissant que les résultats sont bien associés à la bonne personne.

Détection d'alcool via capteur :
Le système est connecté à un capteur d’alcool. Lorsqu’un test est effectué, le taux d’alcool détecté est automatiquement relevé.

Gestion des cas positifs :
Si un chauffeur est détecté positif à l’alcool, le système :

Enregistre les informations du chauffeur identifié

Ajoute la valeur du taux d’alcool détecté

Sauvegarde l’événement dans un historique détaillé, associé à ce chauffeur

Objectif
L’objectif est de fournir un outil automatisé, fiable et sécurisé pour :

Renforcer la sécurité routière

Prévenir la conduite sous influence

Assurer une traçabilité complète des tests effectués

Ce système peut être utilisé dans des contextes variés tels que les entreprises de transport, les services de sécurité, ou les programmes de prévention.
